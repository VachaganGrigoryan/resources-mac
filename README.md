# Resources for Mac

A macOS system monitor written in Rust with [egui](https://github.com/emilk/egui): CPU, memory, GPU, drives, network, battery, processes and apps.

Inspired by [GNOME Resources](https://apps.gnome.org/Resources/) by nokyan and contributors. This is an independent project and is not affiliated with GNOME.
