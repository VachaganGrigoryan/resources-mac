Find the gigabytes your projects can rebuild.

Disk Sweep scans the folders you choose and tells project files apart from dependencies, build output, editor metadata and git history. It suggests what to move to the Trash, tells you how to get each item back, and does the same for Docker.

brew install --cask VachaganGrigoryan/tap/disk-sweep

Or download disk-sweep.dmg. Needs macOS 13 or later, runs natively on Apple Silicon and Intel.

Disk Sweep

Before anything moves

  • Folders go to the Trash, so you can put them back. Docker clean-ups are permanent, and the dialog says so.
  • Nothing moves until you confirm a dialog that shows how many items and how much space.
  • Each repository's .gitignore decides. Folders with common names such as build, dist or vendor are suggested only when they are ignored.
  • Symbolic links are never followed, and a nested repository keeps its own rules.

Install

Homebrew

brew install --cask VachaganGrigoryan/tap/disk-sweep

Download

Get disk-sweep.dmg from the latest release and drag Disk Sweep to Applications. With it installed, the Free Up Space… button on a drive page in Resources opens it.

Build from source

You need a Rust toolchain.

git clone https://github.com/VachaganGrigoryan/resources-mac
cd resources-mac
cargo run -p disk-sweep --release

First launch

Releases are not notarized, so macOS blocks the app the first time. Open System Settings, then Privacy & Security, scroll down and click Open Anyway. Or run:

xattr -dr com.apple.quarantine "/Applications/Disk Sweep.app"
