See what your Mac is doing. Free the space it doesn't need.

Two small, free and open-source apps with the look of GNOME Resources. They share one design and install side by side.

Resources

Every app, process, processor core, drive and connection in one quiet window. Keep a few numbers in the menu bar or a live graph on your desktop.

brew install --cask VachaganGrigoryan/tap/resources-mac

Disk Sweep

Finds dependencies, build output, editor files and unused Docker data in your project folders, and moves what you pick to the Trash.

brew install --cask VachaganGrigoryan/tap/disk-sweep

Install

Homebrew

Install one or both.

brew install --cask VachaganGrigoryan/tap/resources-mac
brew install --cask VachaganGrigoryan/tap/disk-sweep

Download

The latest release has resources-mac.dmg and disk-sweep.dmg. Open one and drag the app to Applications.

Build from source

You need a Rust toolchain.

git clone https://github.com/VachaganGrigoryan/resources-mac
cd resources-mac
cargo run -p resources-mac --release
cargo run -p disk-sweep --release

First launch

Releases are not notarized, so macOS blocks each app the first time. Open System Settings, then Privacy & Security, scroll down and click Open Anyway. Or run:

xattr -dr com.apple.quarantine /Applications/Resources.app
xattr -dr com.apple.quarantine "/Applications/Disk Sweep.app"
